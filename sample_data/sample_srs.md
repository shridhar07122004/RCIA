# Campus Access Portal — Software Requirements Specification

## Functional requirements

FR-01: Users can log in using email and password.

FR-02: The system validates the user's password before starting an authenticated session.

FR-03: Users can reset their password through a verification email.

FR-04: The system manages authenticated user sessions after successful login.

## Non-functional requirements

NFR-01: The system must protect sensitive user information during authentication and account recovery.

NFR-02: Login responses should complete within two seconds under normal load.
